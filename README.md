# Online Resume Builder

This online resume builder assists job searchers in building a professional resume, making the task of creating a resume easier. Individuals fill out a form that includes questions across required sections such as personal information, educational qualifications, work experience, hobbies, and skills. The system dynamically generates a well-structured resume with customizable templates automatically. Users can print their resume directly or download it as a PNG or PDF.

## Key Features

- **Multi-Step Resume Builder Form**: Step-by-step form navigation for personal details, experience, education, skills, interests, achievements, and languages.
- **Multiple Resume Templates**: Includes Stanford, Harvard, and Edinburgh templates.
- **Color Customization**: Accent color customization swatches for template headers and sidebars.
- **Profile Photo Upload**: Real-time image upload preview with file type and size validation.
- **Export Options**: Download resumes directly as image files (PNG) or print/save as PDF.
